Đang chờ file đầu vào...
  • File XLSM đã mở khóa: mở bằng Excel, nếu hiện thông báo kiểu “The project file contains invalid key…” thì cứ bấm OK/Yes, sau đó vào Alt+F11 → Tools → VBAProject Properties → Protection để đặt mật khẩu mới (hoặc bỏ khóa) rồi lưu lại file.
  • Code VBA được giải nén đúng chuẩn MS-OVBA từ vbaProject.bin nên đầy đủ từng module, đúng thụt lề — kể cả khi VBA đang bị khóa mật khẩu.
  • Toàn bộ xử lý chạy ngay trên trình duyệt của bạn, file không được gửi lên máy chủ nào.
  • Nếu trình duyệt hiện “Trang không phản hồi”: hãy bấm “Chờ” (đừng thoát trang) — đó là lúc một khâu nặng đang chạy; nhìn dòng “Khâu hiện tại” dưới thanh % và các mốc thời gian trong nhật ký để biết đang ở bước nào.
